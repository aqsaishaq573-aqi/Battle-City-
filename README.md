# 🎮 Battle City — AI Lab Project

A Python/Pygame recreation of the classic **Battle City** (NES, 1985) featuring multiple AI algorithms implemented for different enemy tank behaviours.

## 📸 Gameplay Overview

Three progressively harder levels, each showcasing a distinct AI technique:

| Level | Name | Enemy Mix | AI Used |
|-------|------|-----------|---------|
| 1 | Brick Maze | Basic (BFS) + Fast (Greedy/A\*) | Search Algorithms |
| 2 | Steel Fortress | Fast · Armor · Power tanks | Search + CSP Map |
| 3 | Tank Commander | Boss tank | Minimax + Alpha-Beta |

---

## 🧠 AI Algorithms Implemented

### 1. Search (`modules/search.py`)
- **BFS** — BasicTank navigates toward the Eagle using breadth-first search.
- **Greedy Best-First** — FastTank pursues the player using Manhattan-distance heuristic.
- **A\*** — ArmorTank/PowerTank pathfind with terrain-weighted costs (brick = 3, steel = ∞).
- **Line-of-Sight (LOS)** — All tanks check visibility before firing.

### 2. CSP Map Generation (`modules/csp_map.py`)
- Each level's map is procedurally generated using **Constraint Satisfaction**.
- Variables: each grid cell's terrain type.
- Constraints: spawn safety zones, eagle protection rings, reachability guarantees.
- Arc-consistency enforced via **AC-3** (optimised to enqueue only affected neighbours).

### 3. Minimax + Alpha-Beta (`modules/minimax.py`)
- The **Boss tank** (Level 3) uses minimax with alpha-beta pruning.
- Search depth scales with boss phase (more HP → deeper search).
- Evaluation function weighs boss HP, player HP, distance to eagle, and LOS.
- Stats tracked per turn: pruned vs unpruned node counts.

## 🏟️ Game Rules

- **Objective:** Destroy all enemy tanks without losing the Eagle (base).
- **Player lives:** 10. Losing all lives → Game Over.
- **Eagle destroyed** → Immediate Game Over.
- **Win:** Clear all tanks in all 3 levels.

### Tank Types

| Tank | HP | Speed | Fire CD | AI Behaviour |
|------|----|-------|---------|-------------|
| Player | 1 | 3 | 30 | Human input |
| Basic | 1 | 4 | 90 | BFS to Eagle |
| Fast | 1 | 2 | 45 | Greedy chase → Eagle |
| Armor | 4 | 3 | 60 | A\* pathfinding, retreats when low HP |
| Power | 2 | 3 | 50 | A\* + aggressive fire |
| Boss | 10 | 4 | 60 | Minimax (phases scale with HP) |

---

## ⚙️ Level Details

### Level 1 — Brick Maze
- Pool of 20 enemies: 7 Basic → 13 Fast (Fast tanks locked until 7 kills).
- Map: CSP-generated brick maze with 2-ring eagle protection.

### Level 2 — Steel Fortress
- Pool of 20 enemies: 9 Fast · 7 Armor · 4 Power (ratio 4:3:2 per spec).
- Map: CSP-generated steel fortress with 1-ring eagle protection.

### Level 3 — Tank Commander
- Single Boss tank with 10 HP and 3 combat phases.
- Phase 1 (HP 10–7): Minimax depth 2.
- Phase 2 (HP 6–4): Minimax depth 3, more aggressive.
- Phase 3 (HP 3–1): Minimax depth 4, targets eagle directly.
- Boss arena: 12×12 tile enclosed area generated by CSP.

## 📐 Architecture Notes

- **No circular imports:** `renderer.py` imports from `constants.py` only; `game.py` imports renderer inline where needed.
- **CSP map** returns `(grid, eagle_pos)` tuple — Level unpacks both for correct eagle placement per level.
- **Minimax stats** reset at BossTank init; pruned/unpruned counts displayed on the sidebar HUD.
